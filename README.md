CAIXA ELETRÔNICO EM C

Sobre o projeto:
- Este projeto simula o funcionamento de um caixa eletrônico utilizando a linguagem de programação C.
- O programa permite consultar o saldo, realizar depósitos e efetuar saques, além de exibir mensagens de erro para operações inválidas.

Funcionalidades:
- Consultar saldo bancário
- Realizar depósitos
- Realizar saques
- Verificar saldo insuficiente
- Validar valores de depósito e saque
- Encerrar o programa pelo menu
  
Tecnologias utilizadas:
- Linguagem C
- Biblioteca stdio.h
- Estruturas condicionais (if e else)
- Estrutura de seleção (switch)
- Laço de repetição (do...while)
  
Como executar:
- Baixe ou clone este repositório.
- Abra o arquivo main.c em um compilador C.
- Compile e execute o programa.
- Utilize o menu para escolher as operações.
  
Objetivo:
Projeto desenvolvido para praticar conceitos básicos de programação em C, como variáveis, entrada e saída de dados, estruturas condicionais e laços de repetição.
